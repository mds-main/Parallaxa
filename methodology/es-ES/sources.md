# Fuentes

Las investigaciones buscan primero fuentes primarias.

| Nivel | Qué incluye |
|---|---|
| 1. Primarias | Estadísticas oficiales (INE, Eurostat, BLS, Census, OCDE, OMS), sentencias, legislación, transcripciones y grabaciones completas, investigación revisada por pares. |
| 2. Investigación y agencias | Revisiones sistemáticas, institutos de investigación de prestigio, agencias de noticias. |
| 3. Medios | Medios consolidados de todo el espectro político. |
| 4. Solo contexto | Todo lo demás, incluidas publicaciones en X y otras redes. Nunca basta por sí solo para calificar. |

Reglas:

- Solo se puede calificar una afirmación como respaldada o contradicha con al menos dos fuentes independientes, una de ellas de nivel 1 o 2.
- El nivel se asigna según el dominio de la fuente, nunca según lo que diga un modelo.
- Cada cita se comprueba palabra por palabra en la página. Las citas no verificadas se eliminan.
- Las páginas se descargan con protecciones contra instrucciones ocultas: se eliminan scripts, comentarios y texto oculto, y nada de una página puede cambiar nuestras instrucciones.
- Se avisa de las pruebas con más de 12 meses.
